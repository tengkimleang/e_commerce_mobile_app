# Security Policy

## Supported Versions

Please ensure you are using a supported version before reporting an issue. We provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | Yes                |
| 1.1.x   | Yes                |
| 1.0.x   | No                 |

## Reporting a Vulnerability

We take the security of this .NET project seriously. Please **do not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, please report them securely using GitHub's Private Vulnerability Reporting feature.

### How to Report

1. Go to the [Security tab](../../security/advisories) of this repository.
2. Click on **Advisories** in the left sidebar.
3. Click the **Report a vulnerability** button.
4. Fill out the form with as much detail as possible, including:
   - A clear description of the vulnerability.
   - Step-by-step instructions to reproduce the issue.
   - Any relevant logs, screenshots, or proof-of-concept code.

### What to Expect

1. **Acknowledgment:** We will review your report and acknowledge it within **48 hours**.
2. **Triage & Fix:** We will investigate the issue in a private workspace. If confirmed, we will develop a patch.
3. **Disclosure:** Once the patch is released, we will coordinate public disclosure and gladly credit you for the discovery!
